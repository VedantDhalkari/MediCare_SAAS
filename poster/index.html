❗ Problem Statement

Legacy healthcare scheduling mechanisms rely on manual phone calls and paper registers, triggering critical operational bottlenecks:

  • Excessive Wait Times: Unmanaged patient walk-ins cause heavy physical hospital congestion and delays.
  • Slot Collisions & Overbooking: Absence of real-time synchronized doctor calendars across departments.
  • Diagnostic Inefficiencies: Patients arrive unprepared for specialized medical packages (e.g., fasting missed).
  • Data Fragility: Unstructured record storage prone to corruption, lacking ACID compliance and cloud resilience.

🎯 Project Objectives

  • Unified Patient Portal: Interactive UI to explore doctor credentials, fees, and instant slot reservations.
  • Diagnostic Package Workflow: Automated medical test scheduling with mandatory preparation instructions.
  • Executive Admin Dashboard: Real-time doctor schedule control, appointment statuses, and analytics.
  • 100% PostgreSQL ACID Storage: Strict relational models (Sequelize ORM) with relational integrity.
  • Cloud-Native EC2 Deployment: Multi-container Docker Compose with Nginx proxy on AWS Free Tier.

🏛️ Architectural Highlights

  • Dual-Portal Micro-Routing: Unified Nginx ingress routing public traffic on port 80 and hospital admin controls on port 8080.
  • Automated Swap Virtualization: Configured 2GB swap space on AWS EC2 (t2.micro) ensuring smooth Vite asset builds.
  • Dynamic API Fallback: Environment-aware API endpoint auto-detection eliminating cross-origin CORS faults.
  • Relational Data Models: Strongly-typed tables for Doctors, Services, and Appointments with foreign keys.

🏁 Conclusion

The Cloud-Based Hospital Appointment System replaces physical queues with a containerized platform. Built with PostgreSQL and AWS, the system proves that enterprise-grade medical scheduling can be deployed securely and reliably at zero hosting cost.
