❗ Problem Statement

Legacy healthcare scheduling mechanisms rely on uncoordinated phone bookings and paper registers, triggering critical operational bottlenecks:

  • Excessive Wait Times: Long hospital queues resulting from unmanaged patient walk-ins and scheduling overlaps.
  • Slot Collisions & Overbooking: Absence of real-time multi-channel doctor calendar synchronization.
  • Diagnostic Inefficiencies: Patients arrive unprepared for specialized medical packages (e.g., fasting guidelines missed).
  • Data Fragility & Scalability: Unstructured record storage prone to corruption, lacking ACID compliance and cloud elasticity.

🎯 Project Objectives

  • Unified Patient Portal: Deliver an interactive interface for exploring doctor credentials, fees, and instant slot reservations.
  • Diagnostic Package Workflow: Streamline health test packages with mandatory patient instructions and automated time allocations.
  • Executive Admin Dashboard: Empower clinical staff with real-time doctor availability management and revenue analytics.
  • 100% PostgreSQL ACID Architecture: Migrate from document stores to strict relational models (Sequelize ORM) with relational integrity.
  • Cloud-Native EC2 Deployment: Implement multi-container Docker Compose with Nginx reverse proxying on AWS Free Tier.

🏛️ Architectural Design Highlights

  • Dual-Portal Micro-Routing: Unified Nginx ingress routing public traffic on port 80 and hospital admin controls on port 8080.
  • Automated Swap Virtualization: Configured 2GB swap space on AWS EC2 (t2.micro) ensuring smooth Vite asset builds without out-of-memory errors.
  • Dynamic API Fallback: Environment-aware API endpoint auto-detection eliminating cross-origin CORS faults.
  • Relational Data Models: Strongly-typed tables for Doctors, Services, and Appointments with foreign-key constraints.

📊 Results & Key Features

  • Live Specialist Directory: 8 pre-seeded medical specialties with bios, consultation fees, and future slots.
  • Full Diagnostic Booking: Comprehensive full-body checkups and cardiac packages with preparation instructions.
  • Administrative Analytics: Real-time dashboard showing appointment metrics (Completed, Confirmed, Pending, Canceled).
  • Automated 1-Command Deployment: Shell-automated deployment script (`deploy.sh`) and instant git sync (`update.sh`).

🏁 Conclusion

The Cloud-Based Hospital Appointment System successfully replaces legacy physical queues with a high-performance, containerized digital platform. Built with PostgreSQL and AWS, the system proves that enterprise-grade medical scheduling can be deployed securely and reliably at zero hosting cost.
